💡 核心理念

  • No MCP - 用 Skills + README 替代 MCP
  • No 子代理 - 用 tmux 或 Extensions 实现
  • No 权限弹窗 - 用容器或自定义确认
  • No Plan 模式 - 写文件或构建自己的
  • No 内置 Todo - 用 TODO.md 或自定义实现
  • No 后台 bash - 用 tmux 保持可观察性

📥 安装与配置

系统要求

  • Git: 用于会话存储和包管理 (下载)
  • Node.js: v18+ (推荐 v20+) (下载)
  • 包管理器: npm, yarn, pnpm, bun
  • 操作系统: macOS, Linux, Windows, Termux (Android)

安装步骤

# 1. 全局安装
npm install -g @mariozechner/pi-coding-agent

# 2. 验证安装
pi --version

# 3. 认证 (二选一)
# 方式A: API Key
export ANTHROPIC_API_KEY=sk-ant-...

# 方式B: 订阅登录
pi
/login  # 交互式选择提供商

settings.json 配置样例

全局配置: ~/.pi/agent/settings.json，项目配置: .pi/settings.json

{
  // 思考层级: off, minimal, low, medium, high, xhigh
  "thinkingLevel": "medium",
  
  // 压缩设置
  "compaction": {
    "enabled": true,
    "trigger": "auto"
  },
  
  // 重试设置
  "retry": {
    "enabled": true,
    "maxRetries": 3
  },
  
  // 消息投递模式
  "steeringMode": "one-at-a-time",
  "followUpMode": "one-at-a-time",
  
  // 传输协议: auto, sse, websocket
  "transport": "auto",
  
  // 启用技能命令 (如 /skill:name)
  "enableSkillCommands": true,
  
  // 默认工具
  "tools": ["read", "bash", "edit", "write", "grep", "find", "ls"],
  
  // 默认模型
  "defaultModel": "anthropic/claude-sonnet-4-5",

    "~/.claude/skills"

💡 shellPath 配置说明

  • Windows: 建议配置为 Git Bash 路径，支持更好的 bash 命令
  • macOS/Linux: 通常无需配置，使用系统默认 shell
  • 配置位置: ~/.pi/agent/settings.json

1️⃣ 内置工具 - 代码操作的基础

AI 可以使用的 7 个基础工具

工具命令能做什么
📖 read内置读取文件内容，支持大文件自动分片读取
✏️ write内置创建新文件或覆盖整个文件
🔄 edit内置精确替换文件中的特定文本（diff 编辑）
💻 bash内置执行任何 shell 命令（npm, git, node...）
🔍 grep内置在文件中搜索匹配的文本
📁 find内置按名称或模式查找文件
📄 ls内置列出目录内容和文件信息

💡 工作原理：当你描述一个任务时，AI 会分析需要哪些工具，
然后自动调用相应的工具来完成任务。比如你说"帮我创建登录页面"，
AI 会用 read 了解项目结构，用 write/edit 创建文件，用 bash 启动服务器预览

2️⃣ 会话管理 - 不丢失任何工作

智能保存与恢复

📁 自动保存

会话自动保存到 ~/.pi/agent/sessions/

  • 按工作目录自动分类
  • JSONL 格式，保留完整历史
  • 即使重启也不会丢失

⏯️ 继续会话

  • pi -c 继续上次会话
  • pi -r 选择历史会话
  • pi --session <id> 指定会话

🌲 树形结构

支持分支，保留所有探索路径

# 查看会话树
/tree

# 从某点创建新分支
/fork

# 标记重要节点
/l  # 按 l 键标记

📦 对话压缩

长会话自动压缩总结，节省 token

  • 自动触发（上下文快满时）
  • /compact 手动压缩
  • 原始历史仍保存在文件中

5️⃣ 思考层级 - 按需调整

6 个思考级别，适应不同任务

层级速度深度适用场景
off⚡⚡⚡⚡⚡基础简单查询、格式化输出
minimal⚡⚡⚡⚡略深简单编码任务

🎮 四种运行模式

官方定义（pi.dev）

"Pi runs in four modes: interactive, print or JSON, RPC for process integration, and an SDK for embedding in your own apps."

模式总览

模式命令使用场景
交互模式pi (默认)日常编程、复杂任务
打印模式pi -p快速查询、单次任务
JSON 模式pi --mode json集成到其他工具
RPC 模式pi --mode rpc嵌入 IDE/应用

1️⃣ 交互模式 (Interactive)

最常用的模式，完整的终端 UI

# 基本启动
pi

# 带初始提示
pi "帮我创建一个 React 登录页面"

# 继续上次会话
pi -c

# 浏览选择历史会话
pi -r

特点: TUI 界面、会话保存、实时交互、流式输出

2️⃣ 打印模式 (Print Mode)

非交互式，适合脚本和管道操作

# 打印输出后退出
pi -p "列出 src 目录下的 TypeScript 文件"

# 管道输入
cat README.md | pi -p "总结这段文本"

# 带文件引用
pi @code.ts @test.ts "Review these files"

# 只读审查模式
pi --tools read,grep,find,ls -p "审查代码 bug"

特点: 单次执行、自动退出、支持管道、适合 CI/CD

3️⃣ JSON 模式 (JSON Event Stream)

输出完整的事件流，用于集成到其他工具

# 基本用法
pi --mode json "List files"

# 输出格式示例
{"type":"session","version":3,"id":"uuid"}
{"type":"agent_start"}
{"type":"message_update","assistantMessageEvent":{"type":"text_delta","delta":"Hello"}}
{"type":"agent_end","messages":[...]}

# 实用命令
pi --mode json "List files" | jq -c 'select(.type == "message_end")'

4️⃣ RPC 模式 (RPC Mode)

完整的 API 接口，用于嵌入其他应用

核心命令

  • prompt - 发送用户消息
  • steer - 队列转向消息
  • follow_up - 队列后续消息
  • abort - 中止当前操作
  • new_session - 开始新会话
  • set_model - 切换模型
  • compact - 压缩上下文

应用场景

  • 🖥️ 嵌入 IDE/编辑器插件
  • 🌐 构建 Web 应用前端
  • 📱 开发桌面应用
  • 🤖 机器人/自动化工具

模式对比总结
